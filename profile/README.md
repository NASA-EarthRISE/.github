The Earth Resources for Industry and State Empowerment (EarthRISE) initiative seeks to build community resilience by helping state and local governments, federally-recognized Tribes, territories, and the private sector integrate satellite data into their decision-making. EarthRISE includes the EarthRISE Developers Academy, which builds the next generation of Earth science leaders by working with partners on hands-on projects that apply NASA’s cutting-edge satellite data to real-world challenges.
